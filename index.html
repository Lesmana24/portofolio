Halo! Saya Lesmana.

Perjalanan saya di dunia teknologi bermula dari rasa penasaran sederhana: "Bagaimana cara membuat sesuatu dari layar komputer yang bisa menyelesaikan masalah nyata di sekitarku?" Bagi saya, coding bukan sekadar merangkai sintaksis, melainkan seni menyusun solusi yang intuitif dan bermanfaat bagi orang lain.

Sebagai mahasiswa Teknik Informatika, saya sering menghadapi berbagai tantangan logika rumit—mulai dari mengelola arsitektur database kasir yang padat, merancang alur transaksi laundry yang rapi, hingga menghubungkan sensor hardware IoT di lahan pertanian dengan kecerdasan buatan AI.

Saya suka mengubah ide menjadi aplikasi web fungsional menggunakan ekosistem React & Node.js. Untuk backend yang tangguh dan terstruktur, Laravel dan Go (Golang) sering menjadi senjata utama saya. Di luar browser, saya antusias bereksperimen dengan mikrokontroler ESP32, protokol MQTT, serta implementasi Computer Vision & LLM.

Engine FEFO

SIMRS FEFO — Manajemen Stok & Kedaluwarsa Obat Rumah Sakit

Masalah & Latar Belakang

Risiko obat kedaluwarsa terpakai pada operasional rumah sakit dan kerugian finansial akibat penumpukan stok expired, serta potensi human-error petugas farmasi saat memilih batch obat secara manual.

Tantangan Unik

Mengembangkan sistem Full-Stack (Backend Go/Gin & Frontend React 19/Vite 8) dengan transaksi atomik database (SELECT FOR UPDATE) untuk mencegah race condition pemotongan stok, serta engine simulasi live FEFO (First Expired, First Out) secara real-time.

Dampak & Solusi Teknis

Otomatisasi pemotongan stok berurutan berdasarkan expired date terdekat, proteksi mutasi stok ganda secara konkuren, indikator visual status expired (Aman, Mendekati, Kadaluwarsa), dan UI glassmorphism modern dual-theme.

"Memastikan keselamatan pasien dan efisiensi farmasi melalui otomatisasi pemotongan stok obat berbasis tanggal kedaluwarsa terdekat."
Go (Golang) Gin React 19 Vite PostgreSQL GORM Tailwind CSS Framer Motion JWT Auth
